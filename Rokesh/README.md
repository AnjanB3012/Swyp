# warden-mesh

## What this is

warden-mesh is a Buyer agent and a Seller agent that discover each other via ANS (Agent Name Service), verify each other's identity, and negotiate a deal. The system's design defends against forged signatures, replayed requests, and swapped quotes throughout the negotiation.

## Threat model

- Forged signatures
- Replayed requests
- Swapped quotes
